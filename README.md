1.项目：用于分析航空延误的项目
2.工具：pandas 和 matplotlib
3.数据来源：从Kaaggle里面找到的有关2008年美国各个航班的航班数据，其中的字段包括航班信息（航司、航班号、起降机场），时间信息，延误指标（到达/出发延误），延误原因（天气、空域、航司、晚到、安检  ）等30列，共计192万行 30列
4.分析过程：读取数据--对数据进行了描述--通过分类聚合得到了各个航司的延误率及其数量--通过各个航司的的延误率和总体延误率的比较得到总体延误趋势--比较某个航司的延误原因占比和总体延误原因占比并为这个航司并为该航司记录各个原因的占比，找出其最主要延误原因--对YV航司和全部航司的延误时间进行了饼图绘制
5.结论：
（1）YV航司延误率最高，高达0.742，并且航班数为6万。
（2）YV航司的航司原因占比为52.9% ，全部航司的航司原因占比为30.3%， 因此对于YV航司主要是航司原因导致延误，说明YV航司因自身原因导致延误的比例显著高于整体水平，建议重点关注内部运营问题。
（3）60% 的航司延误率高于平均，说明延误普遍偏高，未出现单家极度异常；但航司间仍有差距（最高 74.2% vs 最低 43.1%），高延误航司仍值得关注。
