1.项目：用于分析航空延误的项目
2.工具：pandas 和 matplotlib
3.数据来源：从Kaggle里面找到的有关2008年美国各个航班的航班数据，其中的字段包括航班信息（航司、航班号、起降机场），时间信息，延误指标（到达/出发延误），延误原因（天气、空域、航司、晚到、安检  ）等30列，共计192万行 30列
4.分析过程：读取数据--通过df.describe 和 count_values对数据进行了描述--通过分类聚合得到了各个航司的延误率及其数量--通过各个航司的的延误率和总体延误率的比较得到总体延误趋势--比较YY航司与全部航司的延误原因占比，找出YY航司最主要的延误原因--对YV航司和全部航司的延误时间进行了饼图绘制
5.结论：
（1）YV航司延误率最高，高达0.742，并且航班数为6万。
（2）YV航司因自身原因导致的延误占比为52.9%，而全部航司该占比的平均水平是30.3%，说明YV航司自身运营问题对延误的影响显著高于行业平均，建议重点关注内部管理优化。
（3）60% 的航司延误率高于平均，说明延误普遍偏高，未出现单家极度异常；但航司间仍有差距（最高 74.2% vs 最低 43.1%），高延误航司仍值得关注。
